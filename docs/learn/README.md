# Learn

Start here when learning HypeR rather than looking up a specific command or ABI.

1. [Getting started](getting-started.md): prerequisites, configuration and a first QEMU boot.
2. [System architecture](../architecture/overview.md): the Native, kernel and I/O VM boundaries.
3. [Reading the code](reading-the-code.md): follow boot, syscalls, IPC, scheduling, memory and VM lifecycles through their owners.
4. [Development workflow](https://hyper-proj.github.io/build/docs/development.html): editor setup, tests and contribution checks.

For daily operation, use the [usage manuals](../usage/README.md). Exact protocol
and lifetime rules belong in [detailed design](../design/README.md).
