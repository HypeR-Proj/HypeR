# HypeR documentation

[Quick start](learn/getting-started.md) · [Architecture](architecture/overview.md) · [Roadmap](project/roadmap.md)

Each component maintains and publishes its own documentation after changes merge into `main`. This repository provides system introductions and navigation.

The [module documentation catalog](https://hyper-proj.github.io/manifest/modules.html)
is generated from the source manifest. Adding a module updates that catalog when
the manifest merges; this introduction does not keep a second module list.

This repository owns system-wide architecture, concepts, getting started and the
project roadmap. Module APIs, build details and usage belong to their owners.
